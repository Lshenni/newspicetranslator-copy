# IEEE Outputs

This folder contains reproducible artifacts for an IEEE journal/conference submission.

## Contents
- EVALUATION.md: Experimental setup, datasets, metrics, and reproducible protocol
- run_all.sh: One-command pipeline to regenerate tables and logs
- collect_metrics.py: Extracts summary statistics from corpus validation reports
- figures/: Generated plots (to be produced by your plotting workflow)
- tables/: Generated tables (CSV/LaTeX)

## Quick Start
1) Run the evaluation pipeline via run_all.sh
2) Use the generated tables and logs to fill the paper evaluation section
