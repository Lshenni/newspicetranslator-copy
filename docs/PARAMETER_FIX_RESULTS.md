## Summary

### Problem
Output files were missing **all parameters** from source models, making them unusable for simulation.

### Root Cause
Parser only handled braced model format `model name type { params }`, not inline format `model name type param1=val1 param2=val2`.

### Solution
Enhanced parser to detect and extract both formats.

## Code Changes

### File Modified
[src/parsers/spectre_parser.py](../src/parsers/spectre_parser.py)

### Changes
1. **Enhanced regex** to capture remainder after model type:
   ```python
   # Before: r"model\s+(\w+)\s+(\w+)\s*\{?"
   # After:  r"model\s+(\w+)\s+(\w+)\s*(.*)"
   ```

2. **Added format detection** to handle both inline and braced:
   ```python
   if remainder.startswith("{"):
       return self._extract_braced_model(...)
   elif remainder:
       return self._extract_inline_model(...)
   ```

3. **New method** `_extract_inline_model()`:
   - Extracts parameters from same line as model declaration
   - Returns param_lines with inline parameter string

4. **Refactored method** `_extract_braced_model()`:
   - Separated braced-format logic into dedicated method
   - Maintains backward compatibility
