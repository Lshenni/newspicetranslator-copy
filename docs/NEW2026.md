## Executive Summary

This masterplan details the implementation of a **next-generation SPICE translator** using an **Intermediate Representation (IR)** architecture. This approach eliminates the need for N×(N-1) format-specific translators by introducing a universal IR layer.

### Key Innovation: IR-Based Translation

```
OLD APPROACH (5+ Translators):          NEW APPROACH (IR-Based):
┌──────────┐                            ┌──────────┐
│ Spectre  │──┬──→ ngspice               │ Spectre  │──┐
│          │  └──→ HSPICE                │          │  │
└──────────┘                             └──────────┘  │
                                                       ├──→ IR ──┬──→ Spectre
┌──────────┐                             ┌──────────┐  │        ├──→ HSPICE
│ HSPICE   │──┬──→ ngspice               │ HSPICE   │──┤        └──→ ngspice
│          │  └──→ Spectre               │          │  │
└──────────┘                             └──────────┘  │
                                                       │
┌──────────┐                             ┌──────────┐  │
│ ngspice  │────→ HSPICE                 │ ngspice  │──┘
└──────────┘                             └──────────┘

= 5+ separate translators               = 3 parsers + IR + 3 writers
= High duplication                       = Low duplication
= Hard to maintain                       = Easy to maintain
```

## IR (Intermediate Representation) Specification

### Core IR Classes

```python
# ir/model_ir.py
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Any
from enum import Enum

class Corner(Enum):
    """Process corners."""
    TT = "typical-typical"
    FF = "fast-fast"
    SS = "slow-slow"
    FS = "fast-slow"
    SF = "slow-fast"

class Temperature(Enum):
    """Temperature conditions."""
    COLD = -40
    NOMINAL = 25
    HOT = 125

@dataclass
class Condition:
    """Simulation condition."""
    corner: Corner
    temperature: Temperature
    voltage: Optional[float] = None

@dataclass
class ModelVariation:
    """Parameters for specific condition."""
    condition: Condition
    parameters: Dict[str, Any]
    source_line: int
    source_file: str

@dataclass
class ModelIR:
    """Universal intermediate representation."""
    # Identity
    name: str
    device_type: str  # nmos, pmos, bjt, diode, etc.
    base_model: str   # bsim4, level=54, etc.
    
    # Parameters
    base_parameters: Dict[str, Any] = field(default_factory=dict)
    variations: List[ModelVariation] = field(default_factory=list)
    
    # Metadata
    pdk_name: Optional[str] = None
    version: Optional[str] = None
    source_format: Optional[str] = None
    
    def get_parameters_for_condition(self, condition: Condition) -> Dict[str, Any]:
        """Get merged parameters for specific condition."""
        params = self.base_parameters.copy()
        for var in self.variations:
            if var.condition == condition:
                params.update(var.parameters)
                break
        return params
```

## Translation Workflow

### Step-by-Step Process

```python
# Example: Spectre → ngspice translation

from src.core.translation_engine import TranslationEngine
from pathlib import Path

# 1. Initialize engine
engine = TranslationEngine()

# 2. Execute translation (complete workflow)
result = engine.translate(
    input_file=Path("models.scs"),
    output_file=Path("models.lib"),
    source_format="spectre",
    target_format="ngspice"
)

# Internal workflow:
# ┌─────────────────────────────────────────┐
# │ 1. PARSE (Spectre → IR)                │
# │    - Load file with includes            │
# │    - Extract models and parameters      │
# │    - Build IR structure                 │
# ├─────────────────────────────────────────┤
# │ 2. VALIDATE IR                          │
# │    - Check IR structure                 │
# │    - Validate parameter ranges          │
# │    - Check model consistency            │
# ├─────────────────────────────────────────┤
# │ 3. MAP PARAMETERS (if needed)           │
# │    - Translate parameter names          │
# │    - Handle vendor-specific params      │
# │    - Apply unit conversions             │
# ├─────────────────────────────────────────┤
# │ 4. WRITE (IR → ngspice)                │
# │    - Generate syntax                    │
# │    - Format parameters                  │
# │    - Write output file                  │
# ├─────────────────────────────────────────┤
# │ 5. VALIDATE OUTPUT                      │
# │    - Check syntax correctness           │
# │    - Verify parameter preservation      │
# │    - Optional: Run simulation           │
# └─────────────────────────────────────────┘

print(f"✓ Translated {result.models_translated} models")
print(f"✓ Confidence: {result.confidence_score:.1%}")
```

## Key Features

### 1. **Universal Parser Interface**
```python
class BaseParser(ABC):
    """All parsers implement: parse_to_ir()"""
    
    @abstractmethod
    def parse_to_ir(self, file_path: Path) -> List[ModelIR]:
        """Parse source format to IR."""
        pass
```

### 2. **Universal Writer Interface**
```python
class BaseWriter(ABC):
    """All writers implement: write_from_ir()"""
    
    @abstractmethod
    def write_from_ir(self, models: List[ModelIR], output: Path) -> None:
        """Write IR to target format."""
        pass
```

### 3. **Parameter Mapping System**
- Static mappings from YAML
- Dynamic discovery for unknown parameters
- Confidence scoring
- Vendor-specific handling

### 4. **Validation Pipeline**
- IR structure validation
- Syntax validation

- Optional simulation validation

## Risk Mitigation

### Risk 1: Complex Model Types
- **Mitigation:** Start with MOSFET (BSIM4), expand incrementally
- **Fallback:** Graceful degradation for unsupported types

### Risk 2: Unknown Parameters
- **Mitigation:** Self-learning mapping discovery
- **Fallback:** Pass through with warning

### Risk 3: Vendor-Specific Features
- **Mitigation:** Vendor parameter registry
- **Fallback:** Skip with confidence penalty

### Risk 4: Performance on Large Files
- **Mitigation:** Streaming parser for large files
- **Fallback:** Batch processing with progress bar
